# Archived workflow

Files here preserve superseded code and the initial reconstruction plan. They are retained for provenance and are not part of the supported workflow. Do not run these scripts against historical inputs: several write beside their inputs or depend on stale paths.

Use `python scripts/workflow.py --help` from the repository root. The [workflow guide](../docs/workflow.md) lists the supported commands. [Relocation records](../audit/legacy_relocation.tsv) preserve every old path and file hash.

The archived PVE scripts estimate effects by inverse regression from saved genetic values. They do not recover the original randomly sampled SNP effects or establish the manuscript PVE range. Equation 12/PVE provenance is deferred to Professor Jicai Jiang at the user’s request.
