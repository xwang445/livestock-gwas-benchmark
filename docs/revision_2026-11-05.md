## Reproduce the revision

Use the existing verified computing environment and a new private output directory. The association scripts executed with Python 3.6.8, numpy 1.19.5, pandas 1.1.5, scipy 1.5.2 and matplotlib 3.3.4. The RSS fitter requires susieR 0.14.2. Root validation uses the separately pinned repository dependencies. Set these variables to authorized local inputs; no real source roots are committed:

```bash
python scripts/revision_2026-11-05/association/derive_association_tables.py \
  --benchmark "$GWAS_BENCHMARK_ROOT" --simulation "$ORIGINAL_SIMULATION_DIRECTORY" \
  --genotype-prefix "$VERIFIED_GENOTYPE_PREFIX" --gcta-directory "$GCTA_OUTPUT_DIRECTORY" \
  --output "$NEW_PRIVATE_ASSOCIATION_DIRECTORY"
python scripts/revision_2026-11-05/association/derive_power_sensitivity.py \
  --benchmark "$GWAS_BENCHMARK_ROOT" --gcta-directory "$GCTA_OUTPUT_DIRECTORY" \
  --tables "$NEW_PRIVATE_ASSOCIATION_DIRECTORY/tables"
python scripts/revision_2026-11-05/association/derive_spatial_closed.py \
  --benchmark "$GWAS_BENCHMARK_ROOT" --gcta-directory "$GCTA_OUTPUT_DIRECTORY" \
  --tables "$NEW_PRIVATE_ASSOCIATION_DIRECTORY/tables"
python scripts/revision_2026-11-05/association/derive_overlap_summary.py \
  --tables "$NEW_PRIVATE_ASSOCIATION_DIRECTORY/tables"
python scripts/revision_2026-11-05/association/plot_association_revision.py \
  --tables "$NEW_PRIVATE_ASSOCIATION_DIRECTORY/tables" --output "$NEW_FIGURE_DIRECTORY"
python scripts/revision_2026-11-05/plot_manhattan.py \
  --root "$GWAS_BENCHMARK_ROOT" --gcta-dir "$GCTA_OUTPUT_DIRECTORY" \
  --out "$NEW_MANHATTAN_DIRECTORY" --require-complete --individual
```

The simulation directory must contain the verified chromosome-length table and saved `data_20000/` phenotype files. The benchmark root contains the verified historical window inventory, causal truth and source GWAS files. Detailed association outputs and source-path manifests remain private. The `--require-complete` Manhattan command intentionally refuses missing configurations; omission permits clearly labeled provisional diagnostic plots.

`--individual` adds one PDF/PNG pair for each completed configuration/phenotype. The final complete run produces 100 individual pairs and eleven composite pairs, with relative individual paths in the 100-row manifest. The current 93 completed panels correspond to nine complete configurations plus GCTA phenotypes 1–3; the other seven GCTA rows remain pending. Phenotype 2 and 3 composites were refreshed from validated outputs; pooled Figure 4 remains restricted to the nine complete configurations. A private PI export contains 93 individual PDF/PNG pairs. These individual files are not all committed here; the documented command regenerates them from authorized inputs, and the public manifest records only committed composite coverage.

The [RSS workflow](../scripts/revision_2026-11-05/susie/README.md) and [PR instructions](../finemapping/pr_curve/README.md) give fitting/evaluation commands. A portable GCTA runner is included at `scripts/revision_2026-11-05/run_gcta_mlma.py`; it verifies full FAM/GRM order, input fingerprints, 20,000 phenotype intersections, output SNPs/alleles and completion logs, and locks its output directory. It uses GCTA 1.94.1, full GRM, intercept only and the exact original `--mlma` model. Check active host/scheduler jobs before launching a different output directory.

The [full-GRM content check](../derived_data/revision_2026-11-05/full_grm_spotcheck.json) recomputed 21 selected off-diagonal entries using all 135,358 markers and frequencies from all 31,301 animals. Marker counts matched, and the maximum discrepancy was 2.32 × 10⁻⁹. This is a content spot-check, not complete matrix equality. `scripts/revision_2026-11-05/verify_full_grm.py` reproduces it without exporting individual relationships unless a private-details destination is explicitly requested.

## Unresolved dependencies

The numerical tables and figures describe the explicitly labeled analysis snapshot. Scientific reproduction requires the authorized restricted inputs listed above. Document editing, citation-manager operations, correspondence and internal review records are maintained separately from this analysis repository.

Seven GCTA fits remain outstanding. The canonical tables and figures must be refreshed after their validated completion. A partial run cannot support final GCTA comparisons or a complete resubmission. The current two-panel Figure 7 contains BOLT-LMM and REGENIE_LOCO only; it differs from the older repository's four-panel cached plot and is not SLEMM-dependent. Its variant-level Equation 13 prediction input and original Equation 12 generator are not available locally, so upstream provenance and bin assignments remain unverified. The original SNP-effect/PVE source remains unavailable; inverse-regression reconstruction is not treated as generating truth or as final effect-size-stratified detection evidence.

Regional association, localization spillover and statistical type-I error are distinct. Fewer significant SNPs or loci alone do not establish superior calibration. Conclusions must follow the complete new evidence and be reconciled with the actual PI-edited manuscript and response letter.

The public deliverable contains reproducible scientific source, aggregate tables, independent numerical audits and clearly labeled historical estimators. Individual-level inputs and internal planning/correspondence are excluded.

GCTA heritability is extracted only from completed MLMA logs. The final REML iteration prints Vg and Ve to five decimal places; the table reports their ratio as a rounded-log estimate, with no inferred standard error. The ten-phenotype mean, SD and range remain withheld until all ten analyses complete. See `gcta_heritability_by_phenotype.tsv` and `gcta_heritability_summary.tsv` in the revision association tables. The same extraction runs during canonical association derivation.

The completed GCTA traits have 2, 0 and 32 significant SNPs in 2, 0 and 7 loci, respectively. Phenotype 3 includes six effect loci and one null locus; none of these three traits has a central-null locus. Equal counts do not imply identical regions: GCTA and SLEMM share 2 of 3 union loci for phenotype 1 and 6 of 8 for phenotype 3. Phenotype 2 has two empty sets, for which the retained historical Jaccard convention is undefined. These are phenotype-specific observations, not a ten-phenotype GCTA conclusion.

The actual benchmark generator and variant cache are still needed to verify the LOCO covariance normalization that produced Figure7. Public author-code examples are not treated as proof of the benchmark normalization, and cached predictions are not silently recomputed under a different convention.
