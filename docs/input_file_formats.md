# Input file formats

The scripts expect a small set of common tabular formats.

## GWAS summary tables

Expected columns typically include:

- SNP
- CHR
- BP
- P
- BETA
- SE
- Method
- Method2
- Pheno

## Region definitions

Expected columns for window definition files include:

- CHR
- Start
- End

## Causal variant lists

Expected columns include:

- SNP
- CHR
- BP

The repository does not include proprietary inputs.
