# Polygenic phenotype simulation

[`simulate_polygenic_phenotypes.sh`](simulate_polygenic_phenotypes.sh) builds a genomic relationship matrix (GRM) from the fixed causal-marker set and uses MPH to simulate quantitative phenotype replicates for the GWAS benchmark.

## Design

- Genotypes: PLINK binary files (`.bed`, `.bim`, and `.fam`) sharing one prefix.
- Effect-marker set: 10,000 SNPs sampled from the predefined polygenic-effect windows.
- The same 10,000-SNP set is used to construct the GRM for all phenotype replicates.
- Narrow-sense heritability: `h2 = 0.5`.
- Number of phenotype replicates used in the benchmark: `10`.

The individual-level genotype files and study SNP-information file are not distributed in this repository.

## Requirements

- Bash 3.2 or later.
- MPH available on `PATH`, or its executable supplied through `MPH_BIN`.
- A PLINK binary genotype dataset.
- An MPH-compatible SNP-information file containing the fixed effect-marker set.

## Run

```bash
chmod +x simulate_polygenic_phenotypes.sh
./simulate_polygenic_phenotypes.sh \
  /path/to/genotype/prefix \
  /path/to/snp.info.chr1_18.10k.csv \
  ./simulation_output
```

Pass the PLINK genotype prefix without `.bed`, `.bim`, or `.fam`. The output directory is optional and defaults to `./simulation_output`.

The defaults can be overridden with environment variables:

```bash
MPH_BIN=/path/to/mph \
NUM_THREADS=20 \
NUM_PHENOTYPES=10 \
HERITABILITY=0.5 \
./simulate_polygenic_phenotypes.sh \
  /path/to/genotype/prefix \
  /path/to/snp.info.chr1_18.10k.csv
```

## Outputs

The script writes the following files or file groups under the selected output directory:

- `MPH_grm_chr1_18*`: GRM files created from the effect-marker set.
- `grmlist.txt`: GRM prefix supplied to the MPH simulation step.
- `pheno*`: simulated phenotype output generated by MPH.

The script stops before analysis if the executable or any required input file is missing.

## MPH compatibility note

The script assumes that the installed MPH version accepts the flags shown in the script and a GRM-list file containing one GRM prefix per line. Confirm these options against the documentation for the installed MPH version before a production run.
