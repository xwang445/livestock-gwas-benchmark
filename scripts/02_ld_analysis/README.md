# LD decay

`run_plink_ld.sh` preserves logged PLINK r2 options and seed; explicit resource limits and a new output directory are required. It uses the full 31,301-animal panel. Raw LD remains restricted.

`verify_ld_means.py --input /path/to/ld_10Mb.ld.gz` streams the saved file in chunks, emits only 1,000 mean-R² / count bins, and writes nothing to the input directory. Ten-kb bins are left-closed/right-open, with the final 10 Mb endpoint included. The independent recount matched all saved bin counts and means within 1e-10.

`13_figures/plot_ld.R` reproduces the historical endpoint-constrained natural spline in log10 distance (20 basis columns, equal bin weights) from the verified means. Median panels are optional historical analyses and are not regenerated by this mean-only command.
