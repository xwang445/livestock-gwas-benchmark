# Derived data

This directory contains non-identifying derived summary templates and documentation. The public repository does not include the full GWAS output tables, individual-level phenotype data, or proprietary genotype resources.

Included files:

- method_summary/method_summary_template.tsv
- spillover_summary/spillover_summary_template.tsv
- lambda_gc_summary/lambda_gc_summary_template.tsv
- overlap_summary/overlap_summary_template.tsv
- equation13_summary/equation13_summary_template.tsv

These files are intentionally small and do not contain individual-level or sample-identifying information. Full figure reproduction requires authorized access to the proprietary analysis inputs.
